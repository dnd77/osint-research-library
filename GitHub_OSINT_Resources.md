# GitHub OSINT Resources and Tools

This file supplements the article library with high-value GitHub repositories that are useful for OSINT research, source collection, tooling, automation, and investigation workflows.

## Why these are useful
GitHub contains a large number of OSINT-related repositories, but the strongest ones generally fall into a few categories:
- curated "awesome" resource lists
- recon and intelligence frameworks
- target discovery tools (domains, emails, infrastructure)
- social media and people-search tooling
- website and exposure analysis tools

## Top Recommended GitHub Repositories

### 1) awesome-osint
- Repository: jivoi/awesome-osint
- URL: https://github.com/jivoi/awesome-osint
- Why it matters: This is one of the best general-purpose curated OSINT resource lists on GitHub. It is an excellent starting point for broadening the library.
- Best for: general OSINT discovery, curated links, references

### 2) Awesome-OSINT-List
- Repository: Astrosp/Awesome-OSINT-List
- URL: https://github.com/Astrosp/Awesome-OSINT-List
- Why it matters: Modern, well-organized, and focused on tools and categories for security researchers and OSINT practitioners.
- Best for: tool discovery and category-based research

### 3) OSINT-Framework
- Repository: lockfale/OSINT-Framework
- URL: https://github.com/lockfale/OSINT-Framework
- Why it matters: One of the classic OSINT tool maps. It groups tools by function and source type.
- Best for: learning the landscape of OSINT tools and use cases

### 4) SpiderFoot
- Repository: smicallef/spiderfoot
- URL: https://github.com/smicallef/spiderfoot
- Why it matters: One of the strongest open-source recon and OSINT frameworks, especially for footprinting and data gathering.
- Best for: domain, infrastructure, and exposure analysis

### 5) theHarvester
- Repository: laramies/theHarvester
- URL: https://github.com/laramies/theHarvester
- Why it matters: A classic and practical tool for email, subdomain, and open-source intelligence discovery.
- Best for: domain, email, and subdomain investigation

### 6) web-check
- Repository: lissy93/web-check
- URL: https://github.com/lissy93/web-check
- Why it matters: An all-in-one website analysis and OSINT tool for assessing public exposure and website information.
- Best for: website analysis, footprinting, exposure review

### 7) sn0int
- Repository: kpcyrd/sn0int
- URL: https://github.com/kpcyrd/sn0int
- Why it matters: A semi-automated OSINT framework designed for structured investigation and information gathering.
- Best for: automation, structured recon, intelligence collection

### 8) Osintgram
- Repository: Datalux/Osintgram
- URL: https://github.com/Datalux/Osintgram
- Why it matters: Useful for social media OSINT and Instagram-focused investigation workflows.
- Best for: social media intelligence, SOCMINT

### 9) Photon
- Repository: s0md3v/Photon
- URL: https://github.com/s0md3v/Photon
- Why it matters: A fast crawler for recon and intelligence gathering from public web data.
- Best for: web crawling, footprinting, site intelligence

### 10) tracelabs/awesome-osint
- Repository: tracelabs/awesome-osint
- URL: https://github.com/tracelabs/awesome-osint
- Why it matters: Another strong curated list with a community-oriented perspective.
- Best for: broad OSINT resource discovery and community standards

## Best Use of These Repositories

Treat these repositories as:
- reference libraries
- research start points
- source collection hubs
- examples of practical OSINT tooling
- ways to expand the repo beyond article links

Do not treat them as direct evidence in themselves. The value is in:
- understanding the ecosystem
- evaluating tools by use case
- keeping a structured map of available public-source investigation methods
